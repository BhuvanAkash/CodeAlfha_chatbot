# Basic Rule-Based Chatbot

A simple rule-based chatbot built using Python. It responds to user messages based on predefined rules and demonstrates basic Python programming concepts.

## Features

* Responds to greetings like `hello` and `hi`
* Responds to "how are you"
* Tells the user its name
* Displays the current time
* Provides a help message
* Responds to `thanks` and `thank you`
* Exits when the user enters `bye` or `exit`
* Continuously accepts user input until the chat ends

## Technologies Used

* Python
* `datetime` module

## Concepts Used

* Functions
* `if-elif-else`
* `while` loops
* User input and output
* String manipulation
* Conditional statements
* Python modules

## How to Run

1. Make sure Python is installed on your system.

2. Clone the repository:

```bash
git clone https://github.com/your-username/basic-chatbot.git
```

3. Open the project folder:

```bash
cd basic-chatbot
```

4. Run the program:

```bash
python chatbot.py
```

## Example

```text
Bot: Hello! I'm your chatbot.
Bot: Type 'help' to see what I can do.

You: hello
Bot: Hi! How can I help you?

You: what is your name
Bot: I'm a simple Python chatbot.

You: what is the time
Bot: The current time is 21:45:12

You: thanks
Bot: You're welcome!

You: bye
Bot: Goodbye! Have a nice day.
```
